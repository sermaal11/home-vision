1. Original

Frame real capturado por la cámara. Es la referencia visual que inicia todo el proceso.

2. Greyscale

Se elimina el color para trabajar solo con intensidad. Esto simplifica los cálculos y reduce ruido innecesario.

3. Blur

El desenfoque suaviza pequeños cambios de píxeles para que la detección no reaccione tanto a grano, compresión o variaciones mínimas de luz.

4. Difference

Se compara el frame actual con el anterior. Las zonas claras indican píxeles que han cambiado y podrían ser movimiento.

5. Thresholding

El umbral convierte la diferencia en blanco o negro: blanco si el cambio supera el mínimo configurado, negro si se ignora.

6. Contours

OpenCV agrupa las manchas blancas en contornos. Así pasamos de píxeles sueltos a regiones candidatas de movimiento.

7. Motion Boxes

Los contornos pequeños se descartan y los relevantes se resumen en rectángulos rojos. Esto marca dónde hay movimiento útil.

8. Motion Overlay

Resultado final: las cajas calculadas con la diferencia se dibujan sobre el frame real para entender qué objeto o zona se está moviendo.
