Visión doméstica en local

Un laboratorio para aprender visión por computador desde el navegador.

Home Vision conecta una interfaz Angular con una API FastAPI para capturar frames de cámara, enviarlos como imágenes y visualizar distintas fases de procesamiento con OpenCV.

Abrir Motion Lab Abrir Face Detection

Stack principal

FastAPI, Angular, OpenCV, Docker Compose y Nginx con HTTPS local.

Entrada segura

La cámara usa `getUserMedia`, por eso se prueba desde el origen HTTPS de Nginx.

Salud del backend

Validación rápida de la API y sus módulos de visión.

Captura

El frontend muestra el vídeo original, captura frames en un canvas oculto y los manda al backend como `multipart/form-data`.

Procesamiento

El backend devuelve vistas en escala de grises, blur, diferencia, threshold, contornos, cajas y overlay de movimiento.

Objetivo

Construir una base modular para experimentar con visión doméstica antes de añadir detección y automatizaciones más avanzadas.
