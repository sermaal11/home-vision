Visión doméstica en local

Un laboratorio para aprender visión por computador desde el navegador.

Home Vision conecta una interfaz Angular con una API FastAPI para capturar frames de cámara, enviarlos como imágenes y visualizar distintas fases de procesamiento con OpenCV y MediaPipe.

Mapa de aprendizaje

Cada página enseña una pieza distinta del flujo de visión por computador: captura, transformación de imagen, extracción de landmarks y estimación geométrica.

OpenCV y NumPy

OpenCV opera sobre matrices NumPy: cada frame es una imagen convertida en números. Esa base permite aplicar escala de grises, desenfoque, diferencia entre frames, umbrales y contornos.

MediaPipe

MediaPipe aporta modelos preentrenados para detectar rostros, mallas faciales y manos. El backend usa esos puntos para dibujar resultados y construir estimaciones más complejas.

Geometría de cámara

La pose de cabeza combina landmarks 2D con un modelo 3D aproximado y `solvePnP`, una técnica clásica para estimar orientación a partir de puntos conocidos.
